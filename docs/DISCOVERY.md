# Поиск и уведомления (0.8.3)

## Общий поиск

Раздел «Поиск»: строка (до 120 символов), проект или все доступные проекты, тип объекта. Поиск выполняется по текущей базе, не по копии индекса; `%`, `_` и `!` экранируются. Учитываются ASCII и кириллица без учёта регистра. Показано до 20 записей каждого типа в общей выдаче, до 50 при выборе одного типа; отдельная пагинация (до 100 страниц). Результаты содержат заголовок/номер, проект и внутреннюю ссылку, не содержат исходных PDF, финансовых сумм, сообщений, секретов или полного аудита. Поиск по задачам включает заказчика результата и критерии приёмки. Для счетов можно искать по номеру, ID и составным частям номера. Подборки Book показываются только после штатной проверки доступности привязки и хеша снимка; проверяются до 200 привязок, при превышении лимита уточните проект.

Forum: только связанные темы, живой поиск по выбранному проекту, максимум первые три активные привязки на запрос, с ограничением времени. Для остальных разделов используйте штатный интерфейс Forum. Требуются актуальные индивидуальные credentials и права Forum. При сбое источник помечается как недоступный, остальные результаты сохраняются. Для локальных источников также предусмотрена независимая обработка ошибок SQL. Содержимое внешних CMS, необработанные Logs и сообщения ботов не индексируются. Объекты, защищённые MFA на целевых страницах, исключаются без свежего MFA. Заказы доступны только владельцу, редакторские выпуски — по праву manage. Исторические карточки сайтов и релизов доступны по тем же правам, что их штатные страницы.

## Личные подписки

«Напоминания» → выбрать проект → тип срока, горизонт 0–90 дней, охват. Подписка принадлежит текущему пользователю в текущей организации; она не даёт дополнительных прав. Можно выбрать только свои задачи, договоры и инциденты, у остальных типов — все разрешённые объекты. Повторное сохранение изменяет параметры той же подписки. Отписка удаляет её отметки прочтения. При отзыве доступа подписка становится невидимой и не формирует напоминания; при восстановлении доступа прежние настройки снова действуют. Удаление членства организации удаляет подписки и отметки. Операции защищены CSRF; для защищённых источников также требуется свежий MFA.

На обзоре отображается актуальное число непрочитанных напоминаний по доступным источникам. Центр показывает актуальные непрочитанные/прочитанные напоминания:

- задачи не `done`, открытые вехи и незакрытые спринты;
- выставленные счета с положительным непогашенным остатком (только проведённые receipt/refund, без сумм в выдаче);
- срок уведомления и окончание последней активированной редакции договора, открытые обязательства;
- инциденты в `open` до подтверждения реакции, с точным временем SLA.

Дата включается в выборку до конца горизонта, включая просроченные даты. Календарные сроки считаются по UTC; день срока не считается просроченным, SLA сравнивается по секундам. Нулевой горизонт включает текущий день (для инцидентов — уже наступившее время). Отметка прочтения привязана к подписке, объекту и точному сроку, повтор идемпотентен. Изменение срока даёт новый ключ; завершённые объекты исчезают. Если срок возвращается к прежней дате, сохраняется прежняя отметка. Отметить чужое или уже неактуальное напоминание нельзя. Отметки не заменяют выполнение обязательства или подтверждение реакции.

## Сводка владельцу

«Сводка владельцу» — только действующий владелец организации и свежий MFA. Отчёт по всем проектам или выбранному проекту за горизонт 0–90 дней, с отдельным числом просроченных и общим количеством сроков по типам и проектам. Не зависит от персональных подписок, не смешивает типы сроков и не считает сумму задолженности. Ошибка источника явно помечается, а не интерпретируется как ноль.

Доставка — внутри веб-приложения при открытии раздела; данные вычисляются заново, не требуют cron и не образуют устаревших сообщений. Email, push, внешняя рассылка и регулярная отправка сводки в Bots не включены. Отчёт не является атомарным снимком всех источников: при параллельных изменениях данные актуальны на момент отдельных запросов. Для больших установок настройте лимиты и мониторинг времени поиска: поиск по подстроке выполняется SQL без полнотекстового индекса.
